description: Capture a hardware/software idea in docs/ideas/
argument-hint: "<title>"
---
Create `docs/ideas/<YYYY-MM-DD>-<kebab-title>.md` from `docs/ideas/_template.md`. Title: $ARGUMENTS
Ask for only the essentials: the problem, rough parts, and the board if known. Leave unknowns as `TBD`.
Add a row to `docs/ideas/README.md`. When the idea becomes a project, link it from the project's README and set the
idea's status to `Building -> projects/<name>`.
