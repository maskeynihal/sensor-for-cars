hj60_coolant wiring: ESP32-S3 DevKitC-1, sender mode B

Firmware 2026-11-01 (senderMode = SENDER_MODE_B, batterySense = false, USB power). Pin numbers are GPIO numbers. Pin positions follow the Espressif DevKitC-1 left header (J1). Clone boards can have a different order: always read the GPIO label printed next to the pin.

No diodes or transistors in this version. If the YG wire touches 12 V, GPIO7 can be damaged. Keep the wire well insulated, and add a Schottky diode (e.g. 1N5819) in series with GPIO7 later if you can.
Mode B disconnects the dash temperature gauge. The YG wire goes to this circuit, not to gauge terminal F. Test on the bench with resistors first (table at the bottom). Never connect 12 V to any GPIO or to the 3V3 pin.

3.3 V 5 V GND analog input digital output / input TFT SPI. Coloured tags with the same name are connected (net labels). Every GND is one common ground.

Bench test without the truck

Power the board from USB. Connect a resistor between node VS (the YG wire end) and GND in place of the sender. The BATT tile shows USB, because batterySense is off.

Wire to 12 V through 1 kΩ--FAULT-BACKFEED, "WIRE HAS VOLTAGE"

The FSM gives only two sender points, so these values come from a fitted curve. Use 1% resistors or better. Readings within a few °C are normal before the step M5 calibration (ADC_OFFSET_MV).
