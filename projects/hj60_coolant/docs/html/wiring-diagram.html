hj60_coolant wiring: ESP32-S3 DevKitC-1, sender mode B

Firmware as flashed on 2026-11-01 (senderMode = SENDER_MODE_B). Pin numbers are GPIO numbers. Pin positions follow the Espressif DevKitC-1 left header (J1). Clone boards can have a different order: always read the GPIO label printed next to the pin.

Mode B disconnects the dash temperature gauge. The YG wire goes to this circuit, not to gauge terminal F. Test on the bench with resistors first (table at the bottom). Never connect 12 V to any GPIO or to the 3V3 pin.

3.3 V 5 V GND analog input digital output / input TFT SPI. Coloured tags with the same name are connected (net labels). Every GND is one common ground.

Bench test without the truck

Power the board from USB. Connect a resistor between node VS (the YG wire end) and GND in place of the sender. The battery reads about 0 V without 12 V on wire 18, which is normal on the bench.

The FSM gives only two sender points, so these values come from a fitted curve. Use 1% resistors or better. Readings within a few °C are normal before the step M5 calibration (ADC_OFFSET_MV).
